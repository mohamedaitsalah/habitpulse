# HabitPulse Store

Standalone sales page for HabitPulse.

## Netlify
Create a new Netlify site from the existing `mohamedaitsalah/habitpulse` repository.

- Base directory: `store`
- Build command: leave blank
- Publish directory: `.`

This does not change the existing HabitPulse app deployment.

## Checkout
Set `CHECKOUT_URL` in `script.js` to the live PayPal Payment Link before launch.
